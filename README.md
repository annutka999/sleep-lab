# Somnograph

Веб-синтезатор в виде прибора из лаборатории сна. Настоящий сомнограф записывает сон, а мой играет его: два голоса, пульс, дыхание и звуки снов складываются в одну ночь, от бодрствования до пробуждения. Версия 1.0.

## Как запустить

Открыть папку в VS Code и запустить `index.html` через Live Server. Интернет не нужен, Tone.js, шрифты и картинки лежат прямо в проекте.

## Звук

Два голоса и три фоновых слоя, у каждого свой канал. На каждом канале есть громкость, Solo и Mute.

| Канал          | Что звучит          | Цепочка                                            |
| -------------- | ------------------- | -------------------------------------------------- |
| body (слева)   | синтезатор, 4 волны | Synth → Filter → Chorus → Channel                  |
| brain (справа) | второй синтезатор   | Synth → Vibrato → Filter → PingPongDelay → Channel |
| pulse          | сердцебиение        | MembraneSynth → Channel                            |
| noise          | дыхание             | Noise → AutoFilter → Filter → Channel              |
| dream          | события снов        | FMSynth, NoiseSynth, MembraneSynth → Channel       |

Все каналы сходятся в общую цепочку: Gain → Reverb → Filter → Filter (highpass 45 Hz) → Limiter.

## Музыка

Вся музыка растёт из одного мотива. Тело играет D, A, Bb, F, мозг отвечает сверху двумя фразами. По стадиям сна это звучит так:

- Awake и N1: мотив целиком, ре минор.
- N2: у тела остаются D и Bb, у мозга половина каждой фразы.
- N3: одна долгая нота D, мозг шепчет только первую ноту фразы.
- REM: целотоновый бас Bb, C, D и новые фразы без привычной тональности, высота нот срывается.
- Wake: мотив возвращается октавой выше и в ре мажоре (D, A, B, F#), в фразах мозга появляются F# и C#.

Материал выбирается по положению ручек, поэтому всё это работает и при игре руками.

В Auto night первые 6 секунд звучат только тело и пульс. В конце мотив замолкает, один раз звучит аккорд ре мажор, звук затухает и прибор останавливается.

## Управление

Ручки двигаются мышкой вверх и вниз, двойной клик возвращает значение. Пробел включает и ставит на паузу, цифры 1–6 переключают стадии, клавиша F (или кнопка Finale под лесенкой стадий) играет финал. Если навести курсор на любой элемент, в окне сна появится подсказка.

Что есть на экране:

- окно сна: для каждой фазы своя картина из точек, фраза о том, что видит спящий, и живая линия звука;
- у BODY и BRAIN показана нота, которая играет сейчас, и схема цепочки эффектов с живыми значениями;
- гипнограмма: пунктиром идеальная ночь, розовой линией пройденная. Время ночи идёт плавно, в Auto night строго по плану;
- журнал: смены фаз и события снов с временем;
- четыре столбика delta, theta, alpha и beta показывают, какой ритм мозга сейчас преобладает;
- Dream events: пады играют звук при наведении;
- Rec записывает звук прибора в WAV, без звука компьютера и микрофона. Его я кладу под скринкаст.

## Порядок выступления

Исполняю вручную, примерно три минуты.

1. Rec: прибор включается и играет Awake, мотив целиком.
2. Клавиши 2, 3, 4 по очереди: N1, N2, N3. Мотив рассыпается до одной ноты.
3. Клавиша 5, REM. Играю ручками Echo и Pulse, пады Dream events, Saw на мозге, потом Mute на канале brain.
4. Клавиша 6, Wake. Снимаю Mute, возвращаю волну Tri: мотив в мажоре.
5. Кнопка Finale или клавиша F: финал, последний аккорд.
6. Rec ещё раз, запись сохраняется.
